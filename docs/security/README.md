# docs/security/

Artefatos de segurança do serviço.

Conteúdo planejado:

- `asvs.md` — auto-assessment OWASP ASVS L2 (Phase 7).
- `threat-model.md` — modelo de ameaça baseado em STRIDE para os
  caminhos de placement de lance e finalização (Phase 7).
- `penetration-tests/` — write-ups de pen-tests internos, redacted
  de detalhes sensíveis (Phase 7).

Reportes externos de vulnerabilidade passam pelo processo de
disclosure documentado no `SECURITY.md` da raiz do repo.
